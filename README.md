# Alberto Cabello · Portfolio

Portfolio de Alberto Cabello, AI Engineer en Málaga: una web estática con portada, tres casos y tres demos interactivas sobre agentes de IA, automatizaciones, webs y apps de formación. La portada tiene dos recorridos, uno para clientes y otro para empresas, y cada caso termina en contacto. Se publica en https://alberto-cabello.github.io/.

La web está desarrollada con Claude Code (desarrollo asistido por IA) a partir de los diseños de Alberto. Está hecha con Vite, Preact y TypeScript como sitio multipágina, con modo claro y oscuro, y se publica con GitHub Actions en GitHub Pages.
